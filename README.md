# Roku_Sudoku
 An app created by students at Santa Teresa Highschool under the Roku App Design Challenge. Our app "Roku Sudoku" is a interactive shopping service developed using Roku's specialized language BrightScript, this app intends to combine video streaming and shopping to entice customers to purchase products.
